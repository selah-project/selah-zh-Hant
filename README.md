# 塔納赫 — 繁體中文（selah-zh-Hant）

這裡是譯成繁體中文的希伯來聖經（塔納赫）。每一節經文自成一個檔案，每個中文詞都寫在它所翻譯的希伯來詞旁邊。

> **本譯本由機器完成，正等候說中文之人的耳朵。** 中文若不通順、不自然，或不像人們實際說話的樣子——**就當修正。**
> 每個詞旁都有希伯來文，好讓你看見。

**修改任何地方之前，請先讀 `CONTRIBUTING.md`。** 有些看似錯誤之處，是刻意如此。

## 希伯來文在先

本譯本存在，**是為了引你進入希伯來文**——不是要取代它。真正被誦讀的是希伯來文：它的字母、聲音、意思。這裡的中文
是一扇窗，不是最後的門。兩者不合時，以希伯來文為準。

## 聖名：`雅威`

`יהוה` 寫作 **`雅威`**。不是「主」，不是「耶和華」，也不是單獨的「上帝／神」——**那是傳統的字，屬於見證者，不屬於
我們。** 聖名一旦被拿走、換上別的字，讀者就看不見希伯來文所說的。

`אלהים` 是 **`以羅欣`**。但說到列國的神和偶像時（出 32:8），**用「神明」「眾神」是對的。**

## `⟨את⟩`

`את` 是希伯來文的受詞記號。**中文沒有對應的詞**，所以照希伯來文原樣保留在 `⟨ ⟩` 之中。`⟨ ⟩` 裡的中文字是中文
需要、而希伯來文沒有寫的。

## 檔案的樣子

創世記 1:1（`genesis/1/1.json`）：

```
起初，以羅欣創造了 ⟨את⟩ 諸天和 ⟨את⟩ ⟨那⟩地。
```

申命記 6:4（`deuteronomy/6/4.json`）：

```
以色列啊，你要聽：雅威是我們的以羅欣，雅威是獨一的。
```

每個檔案有：`translation`（整節中文）、`tokens`（每個希伯來詞與它的中文詞）、`model`、`timestamp`、`provenance`
（所用的機器與指示）。
